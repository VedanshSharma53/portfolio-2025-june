# vedanshsharma.me

Personal site of Vedansh Sharma — software engineer in Hyderabad.

Plain HTML, CSS and a little JavaScript. No build step, no framework.

## Files

- `index.html` — all content
- `style.css` — design tokens (light + dark), layout, components
- `script.js` — theme toggle, Hyderabad clock, scroll reveals, count-up numbers, copy-email
- `resume.pdf` — linked from the hero and contact sections
- `CNAME` — custom domain for GitHub Pages

## Run locally

```
python -m http.server 5500
```

then open http://localhost:5500.

## Deploy

Push to `master`; GitHub Pages serves it at vedanshsharma.me.
